## 卡住时的取舍顺序

来源接不通：先完成适配器合同和演示闭环，真实接入继续留待办。并行不稳定：退回 Price → Review 串行。时间不够：削减平台数量、视觉效果和候选数量。不能削减价格条件、同款校验、来源时间和演示标识。

## 参考代码：进度门槛（独立演示）

本例用测试值展示依赖，真实进度仍需填写实际结果，不会自动把手册生成等同软件完成。

```python
checks = {
    "contracts": False, "intent_requirement": False,
    "identity": False, "prices": False,
    "evidence_report": False, "watch_demo": False, "ui": False,
}
day3_ready = all(checks[key] for key in ("contracts", "intent_requirement", "identity"))
demo_complete = all(checks.values())
assert not day3_ready
assert not demo_complete
print("可进入价格阶段：", day3_ready, "演示已完成：", demo_complete)
```
