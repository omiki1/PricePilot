## 怎么记录

每条用例保存：日期、实际环境版本、数据模式、输入、预期、实际结果、通过/失败、run_id 或记录 ID。下面是未来实施的验收规范，这些是未来应用验收；本次仅实际检查了代码使用章中列明的参考片段。

## 固定验收矩阵

| ID | 场景 | 必须得到的行为 |

| W01 | 1900→1799→1750→1850→1780，目标1800 | 仅1799与最后1780各触发一次 |
| W02 | 重复任务执行 | 唯一通知记录，不重复逻辑通知 |
| W03 | SMTP 暂时失败/投递不确定 | 区分可重试失败与 unknown_delivery |
| W04 | 暂停或删除监控 | 不再创建新通知 |
| H01 | 只有少量历史样本 | 不称历史低位，展示数据不足 |
| U01 | 演示来源与真实来源混合 | 每条结果明确标识，演示价不争夺真实最低 |
| U02 | 手机窄屏 | 金额和按钮完整，表格可读 |

演示模式与真实模式应分别运行相关用例。混合模式时，排序按数据模式分组，真实结论不能使用演示数据。

## 五分钟演示脚本

1. **0:00—0:40：** 输入“预算 2000，通勤，戴眼镜，希望头戴式降噪耳机”，展示需求提取和实时阶段。
2. **0:40—1:30：** 展开 same/different/uncertain 结果，说明更便宜旧款为什么没进同款组。
3. **1:30—2:20：** 展开价格组成，展示付款价与返现后成本；切换资格未知的样本，观察条件价单列。
4. **2:20—3:10：** 展示 A/B/C 比较，点击两条评论证据；说明样本范围与未知项。
5. **3:10—4:00：** 收藏商品并设置阈值，运行一次测试监控，展示唯一通知日志。
6. **4:00—5:00：** 模拟一个来源失败或刷新后失效报价，展示降级结果；明确当前是真实接入还是演示闭环。

## 参考代码：价格边界的可执行断言（模块演示）

依赖统一模型、价格引擎和 app/test/fixtures.py。目标 app/test/test_price_edges.py，不触网，不发信。

```python
from datetime import datetime, timezone, timedelta
from decimal import Decimal
from app.test.fixtures import make_offer
from app.ai.agent.multi_agent.schema.shopping_schema import Promotion
from app.ai.tool.price_calculator import calculate_quote

now = datetime.now(timezone.utc)
def coupon(name, amount, **extra):
    return Promotion(
        promotion_id=name, amount=amount, eligibility="eligible",
        valid_until=now+timedelta(minutes=10), evidence_ids=["demo-evidence"],
        **extra,
    )

# 互斥优惠只能选更划算的一项。
offer = make_offer(now, item_price="1000", promotions=[
    coupon("a", "100", exclusive_group="one"),
    coupon("b", "150", exclusive_group="one"),
])
assert calculate_quote(offer, now).payable_amount == Decimal("850")
# 门槛不满足。
offer = make_offer(now, item_price="999", promotions=[coupon("a", "100", min_spend="1000")])
assert calculate_quote(offer, now).payable_amount == Decimal("999")
# 运费未知不会被视为包邮。
assert calculate_quote(make_offer(now, shipping=None), now).payable_amount is None
# 过期报价不能成为已核验金额。
expired = make_offer(now, valid_until=now-timedelta(seconds=1))
assert calculate_quote(expired, now).verification_level == "unverified"
# 返现不是默认付款金额的一部分。
q = calculate_quote(make_offer(now, item_price="2599", estimated_cashback=Decimal("20")), now)
assert (q.payable_amount, q.estimated_net_cost) == (Decimal("2599"), Decimal("2579"))
```

以上通过只证明选定纯逻辑样例，真实 API、模型准确率、数据库事务、浏览器展示与 SMTP 需用真实环境另行验收。
