# 资料、版本边界与后续路线

## 依据分级

- **参考项目中已看到：** FastAPI、LangGraph 状态/节点/检查点、Pydantic 结构化输出、YAML 提示词、PyMySQL、SMTP、Vue CDN、SSE。
- **你补充的已掌握技术：** Redis、PostgreSQL、Neo4j。
- **本手册的设计建议：** 六阶段顺序、字段合同、价格资格分层、默认刷新窗口、排名规则、数据库结构、提醒状态机。
- **尚未证实：** Amazon、京东对你的具体账号和本项目用途的实际接口权限、采集成功率、数据完整性与实时价格。

用户材料提到的 shopping-agent、price-check 等名称没有提供唯一仓库链接，本手册不据此宣称某个仓库已经验证可用，也不承诺其中提及的平台覆盖能力。

## 官方资料入口

查阅日期：2026-09-17。资料用来核对概念，实际 API 以开发时锁定的版本为准，不要求升级到文档最新版。

| 主题 | 官方资料 | 本项目怎么使用 |
|---|---|---|
| 图、状态与 reducer | [LangGraph Graph API](https://docs.langchain.com/oss/python/langgraph/graph-api) | 理解状态更新、边与并行汇合；本项目先串行再优化 |
| 会话检查点 | [LangGraph Persistence](https://docs.langchain.com/oss/python/langgraph/persistence) | 区分图会话状态和业务持久化 |
| 自定义流 | [LangGraph Streaming](https://docs.langchain.com/oss/python/langgraph/streaming) | 沿用已有流能力，包装成项目事件协议 |
| 十进制金额 | [Python Decimal](https://docs.python.org/3/library/decimal.html) | 控制金额精度与舍入；规则仍由平台证据决定 |
| PG 精确数值 | [PostgreSQL Numeric Types](https://www.postgresql.org/docs/current/datatype-numeric.html) | 用 numeric/decimal 保存金额，避免浮点误差 |
| Redis 键与过期 | [Redis Keys and Values](https://redis.io/docs/latest/develop/using-commands/keyspace/) | 报价缓存设置有效期限，不更改原核验时间 |
| 图数据库概念 | [Neo4j Graph Database Concepts](https://neo4j.com/docs/getting-started/appendix/graphdb-concepts/) | 后续以节点、关系和属性描述型号关联 |

## 升级顺序与触发条件

| 优先级 | 升级项 | 什么时候值得做 | 必须保留的边界 |
|---|---|---|---|
| 1 | 完成 Amazon＋京东双源接入 | 首个来源已稳定；另一个已取得适用权限 | 独立核验后才比较跨来源最低 |
| 2 | Redis 缓存与限流 | 同 SKU 被频繁重复查询 | 不跨资格混用缓存，不刷新旧数据时间 |
| 3 | 持久化图状态 | 确实需要服务重启后续聊 | 与业务表、用户授权分开管理 |
| 4 | 更多品类 | 耳机全链路可靠 | 每个品类补充硬规格与测试集 |
| 5 | 评论检索/RAG | 评论规模大，用户要细问长期证据 | 检索内容仍带来源，不能替代证据校验 |
| 6 | Neo4j 型号知识图谱 | 别名/代际/兼容关系出现复杂查询 | 同系列不等于同款，不让图替代价格算法 |
| 7 | 多实例调度 | 单实例不能满足量级或可靠性 | 原子认领、重试、幂等和通知状态一致 |

新增能力前先回答：它解决了哪条当前验收用例之外的真实需求？如果只增加技术名词而不改善决策可信度，就继续维护主线。

## 参考代码：检查本机依赖版本（独立工具）

只读取当前 Python 环境，不安装或升级依赖。输出用于记录你的真实开发版本，不能拿文档里的示例版本替代。

```python
from importlib.metadata import PackageNotFoundError, version

packages = [
    "pydantic", "fastapi", "langchain", "langgraph",
    "langchain-openai", "pymysql", "psycopg", "redis", "neo4j",
]
for package in packages:
    try:
        print(package, version(package))
    except PackageNotFoundError:
        print(package, "not installed")
```

适配器的 SDK 版本另外记录；MCP 后置，不因没有某平台 MCP 而认为无法使用官方 API。
