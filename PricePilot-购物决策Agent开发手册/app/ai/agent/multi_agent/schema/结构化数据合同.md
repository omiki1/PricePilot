# 结构化数据合同：V2 的统一字段源

本章是所有示例的字段依据。把参考代码整理到未来的 `app/ai/agent/multi_agent/schema/shopping_schema.py`，其他章节从这里导入。需要 Python 3.11+、Pydantic 2；具体兼容版本在实施时锁定。

## 与新要求的对应

Intent 只识别 search / compare / price / track；Requirement 提取预算、场景、偏好、避雷条件和指定商品链接。ProductIdentity 表示统一规格，Offer 表示某平台某店铺的报价，PriceQuote 表示某次计算。ProductCard 是前端模型，不把原始报价、计算结果和商品身份塞进同一个浮点价格字段。

价格使用 Decimal；经 JSON 序列化后是十进制字符串。CNY 与 USD 分组，默认不换汇排名。Amazon marketplace 与收货地区必须明确，无法确认运税时付款金额为空。

## 参考代码：核心模型（模块参考）

```python
from datetime import datetime
from decimal import Decimal
from typing import Annotated, Literal
from pydantic import BaseModel, ConfigDict, Field, HttpUrl, AwareDatetime

Money = Annotated[Decimal, Field(ge=0, allow_inf_nan=False)]
Currency = Literal["CNY", "USD"]
Action = Literal["search", "compare", "price", "track"]

class StrictModel(BaseModel):
    model_config = ConfigDict(extra="forbid")

class IntentSchema(StrictModel):
    action: Action
    reason: str

class RequirementSchema(StrictModel):
    category: Literal["headphones"] = "headphones"
    budget_max: Money | None = None
    target_price: Money | None = None  # track 的目标付款金额
    currency: Currency = "CNY"
    use_cases: list[str] = Field(default_factory=list)
    requirements: list[str] = Field(default_factory=list)
    avoid: list[str] = Field(default_factory=list)
    target_urls: list[HttpUrl] = Field(default_factory=list)
    destination: str | None = None
    amazon_marketplace: str | None = None
    missing_fields: list[str] = Field(default_factory=list)
    needs_clarification: bool = False

class ProductIdentity(StrictModel):
    brand: str | None = None
    model: str | None = None
    generation: str | None = None
    variant: str | None = None
    storage: str | None = None
    color: str | None = None
    region: str | None = None
    condition: Literal["new", "used", "refurbished"] | None = None
    bundle: str | None = None
    warranty: str | None = None
    field_evidence: dict[str, list[str]] = Field(default_factory=dict)

class Promotion(StrictModel):
    promotion_id: str
    amount: Money
    min_spend: Money = Decimal("0")
    # 此教学版只支持按商品原价判门槛的定额优惠。
    basis: Literal["item_price"] = "item_price"
    eligibility: Literal["eligible", "unknown", "ineligible"]
    exclusive_group: str | None = None
    stackable_with: list[str] = Field(default_factory=list)
    valid_until: AwareDatetime
    evidence_ids: list[str] = Field(default_factory=list)

class Offer(StrictModel):
    offer_id: str
    product_id: str   # 内部标准商品 ID；源平台商品 ID 另存
    source_product_id: str
    platform: Literal["jd", "amazon"]
    marketplace: str
    title: str
    identity: ProductIdentity
    image_url: HttpUrl | None = None
    product_url: HttpUrl
    affiliate_url: HttpUrl | None = None
    shop_name: str | None = None
    currency: Currency
    destination: str
    buyer_context_hash: str
    item_price: Money
    shipping: Money | None = None
    tax: Money | None = None
    estimated_cashback: Money = Decimal("0")
    promotions: list[Promotion] = Field(default_factory=list)
    stock_status: Literal["in_stock", "out_of_stock", "unknown"]
    eligibility: Literal["eligible", "unknown", "ineligible"]
    observed_at: AwareDatetime
    valid_until: AwareDatetime
    evidence_ids: list[str] = Field(default_factory=list)
    data_mode: Literal["demo", "live"]

class PriceQuote(StrictModel):
    quote_id: str
    offer_id: str
    product_id: str
    currency: Currency
    payable_amount: Money | None
    estimated_net_cost: Money | None
    applied_promotions: list[str] = Field(default_factory=list)
    excluded_promotions: dict[str, str] = Field(default_factory=dict)
    verification_level: Literal["verified", "unverified"]
    freshness: Literal["fresh", "stale", "unavailable"]
    verified_at: AwareDatetime
    valid_until: AwareDatetime
    reasons: list[str] = Field(default_factory=list)
    evidence_ids: list[str] = Field(default_factory=list)

class ReviewTheme(StrictModel):
    label: str
    review_ids: list[str]
    inference: bool = False

class ReviewAnalysis(StrictModel):
    product_id: str
    sample_size: int = Field(ge=0)
    pros: list[ReviewTheme] = Field(default_factory=list)
    cons: list[ReviewTheme] = Field(default_factory=list)
    limitations: list[str] = Field(default_factory=list)

class ProductCard(StrictModel):
    product_id: str
    offer_id: str
    title: str
    platform: str
    marketplace: str
    image_url: HttpUrl | None
    product_url: HttpUrl
    affiliate_url: HttpUrl | None
    purchase_url: HttpUrl
    currency: Currency
    original_price: Money
    payable_amount: Money | None
    estimated_net_cost: Money | None
    data_mode: Literal["demo", "live"]
    price_label: str
    comparison_eligible: bool
    tracking_enabled: bool
    checked_at: AwareDatetime

class ComparisonReport(StrictModel):
    cards: list[ProductCard]
    explanation: str
    limitations: list[str] = Field(default_factory=list)
```

## 字段怎么填

- 不明规格填空；明确不适用的字段可以使用经规则确认的 `not_applicable`，不能用它掩盖缺失。
- 商品图片直接采用许可范围内的 API 图片 URL；缺图显示本地占位。商品图片不自动下载归档。
- affiliate_url 只来自已获准渠道，purchase_url 由后端在普通链接与推广链接间选择；不能由模型捏造。
- observed_at 是真实采集时刻，valid_until 同时受优惠、数据有效期和来源许可约束。
- Offer 字段完整不等于核验成功；需通过来源、规格、费用和资格校验。
- ProductCard 的 comparison_eligible 由比较逻辑确定；货币、收货地或规格不一致时为 false。

此模型只支持第一版 CNY/USD 和定额优惠。比例折扣、其他币种、凑单与跨境汇率必须先扩展合同与测试，不能塞进现有字段猜算。
