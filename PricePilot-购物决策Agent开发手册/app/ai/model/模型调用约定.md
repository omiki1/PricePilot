## 参考代码：模型工厂（模块参考）

目标：`app/ai/model/my_model.py`。依赖 langchain-openai。密钥与模型名从运行环境读取；如使用兼容服务，先验证结构化输出与异步调用，不假设所有服务行为相同。

```python
import os
from langchain_openai import ChatOpenAI

class MyModel:
    @staticmethod
    def get_model():
        model_name = os.environ["SHOPPING_MODEL"]
        api_key = os.environ["SHOPPING_API_KEY"]
        options = {
            "model": model_name,
            "api_key": api_key,
            "timeout": 30,
            "max_retries": 1,
        }
        endpoint = os.environ.get("SHOPPING_BASE_URL")
        if endpoint:
            options["base_url"] = endpoint
        return ChatOpenAI(**options)
```

本例故意不硬编码模型名称、接口地址和 temperature；不同服务支持参数可能不同。模型服务实际费用和速度需用你的配置测量。

## 调用与错误约定

记录节点名、运行 ID、模型标识、耗时与可得的 token 数，避免记录密钥。超时有限重试；结构化校验失败允许一次修复，再失败则降级或请求必要补充。不要让模型凭空补完运费或会员资格。

参考 [LangChain Structured Output](https://docs.langchain.com/oss/python/langchain/structured-output) 理解 response_format；本手册节点使用 create_agent 返回的 structured_response。版本需和 graph/state 章节一起锁定。
