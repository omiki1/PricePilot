# 前端：聊天＋商品卡＋比较页面

V2 不再只展示长段对话。保留原 Vue 单页方式，上方聊天/澄清，中间逐步出现商品卡，下方按币种与目的地分组的比较表，侧边或独立页放收藏。

## 商品卡必须有

API 图片或占位、完整规格、平台/店铺、商品原价、可核验付款金额、优惠明细、预计返现后成本、采集时间、数据模式、来源链接、收藏按钮、允许时的价格提醒按钮。Amazon 与京东都显示平台名；无图不伪造产品图片。

product_url 是普通商品页，affiliate_url 是获准渠道的推广链接，purchase_url 是后端已经选定的跳转 URL。若使用联盟链接，在按钮附近说明可能获得佣金；佣金不影响比较排序。不能自动跳转或自动点击推广链接。

## 参考代码：Vue 2 商品卡模板（界面片段）

放到未来 shopping.html 的 Vue 挂载区。cards 来自后端 ProductCard；此片段不是完整 HTML 文件。需要页面先加载与项目兼容的 Vue 版本。

```html
<section id="shopping-app">
  <p>{{ statusText }}</p>
  <article v-for="card in cards" :key="card.offer_id" class="product-card">
    <img v-if="card.image_url" :src="card.image_url" :alt="card.title"
         loading="lazy" @error="$set(card, 'image_url', null)">
    <div v-else class="image-placeholder">暂无授权商品图片</div>
    <h3>{{ card.title }}</h3>
    <p>{{ card.platform }} · {{ card.marketplace }}</p>
    <strong>{{ priceText(card) }}</strong>
    <p>{{ card.price_label }}</p>
    <small>核验时间：{{ card.checked_at }} · {{ card.data_mode }}</small>
    <p v-if="!card.comparison_eligible">地区、币种或规格不同，单独展示</p>
    <a :href="card.purchase_url" target="_blank" rel="noopener sponsored">
      查看商品
    </a>
    <small v-if="card.affiliate_url && card.purchase_url === card.affiliate_url">
      通过此链接购买，我们可能获得佣金
    </small>
    <button @click="openWatchDraft(card)" :disabled="!card.tracking_enabled">
      {{ card.tracking_enabled ? '设置目标付款价' : '此配置未开放提醒' }}
    </button>
  </article>
</section>
```

## 参考代码：事件驱动卡片更新（界面片段）

未来同页脚本。收到 waiting_input 或监控确认事件时关闭订阅，提交回答/确认后按服务端状态继续。断线自动恢复时同一个 EventSource 会发送 Last-Event-ID；完整刷新页面先取运行快照。

```javascript
new Vue({
  el: '#shopping-app',
  data: {
    cards: [], statusText: '请输入需求或商品链接',
    lastEventId: 0, stream: null, watchDraft: null
  },
  methods: {
    priceText(card) {
      return card.payable_amount === null
        ? '付款金额待确认'
        : card.currency + ' ' + card.payable_amount;
    },
    openWatchDraft(card) {
      if (!card.tracking_enabled) return;
      this.watchDraft = { product_id: card.product_id,
        offer_id: card.offer_id, currency: card.currency, target_price: '' };
      // 接下来显示目的地、资格、邮箱和阈值确认弹层，再 POST /watches。
    },
    subscribe(runId) {
      if (this.stream) this.stream.close();
      this.lastEventId = 0;
      const stream = new EventSource(
        '/shopping/runs/' + encodeURIComponent(runId) + '/events'
      );
      this.stream = stream;
      stream.onmessage = (message) => {
        const event = JSON.parse(message.data);
        if (event.run_id !== runId || event.event_id <= this.lastEventId) return;
        this.lastEventId = event.event_id;
        if (event.event_type === 'candidate_update') {
          this.cards = event.payload.cards;
        }
        if (event.event_type === 'report_ready') {
          this.cards = event.payload.report.cards;
        }
        this.statusText = event.payload.message || event.stage || this.statusText;
        if (['run_finished', 'clarification_required',
             'watch_confirmation_required'].includes(event.event_type)) {
          stream.close();
        }
      };
      stream.onerror = () => { this.statusText = '连接中断，正在恢复订阅'; };
    }
  },
  beforeDestroy() { if (this.stream) this.stream.close(); }
});
```

## 联调要求

聊天文字、卡片和比较页读取同一个 final_report，不自己从文字里提取价格。JS 只显示价格字符串，不计算跨币种差价。示例尚未包含弹层提交、完整错误处理和比较页布局，按 Day 6 补齐。

所有链接先在后端校验 HTTPS、许可域名和商品对应关系；前端不直接使用模型输出 URL。不用 v-html 渲染原始模型内容。新运行清空旧卡，候选不足三款如实展示。

演示模式与真实模式持续标记。无结果、缺运费、无评论、平台权限未开通、SSE 游标过期均有可理解的状态。页面结构见 [参考图](../../参考图/01-流程与页面草图.md)。
